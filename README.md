# BESS-DSS: αξίζει μπαταρία στο φωτοβολταϊκό πάρκο σου;

Σύστημα υποστήριξης απόφασης για μία ερώτηση: ο ιδιοκτήτης ενός φωτοβολταϊκού πάρκου που ήδη λειτουργεί στην Ελλάδα πρέπει να προσθέσει μπαταρία, πόσο μεγάλη, πώς να τη λειτουργεί, και αντέχει η απόφαση σε κακή χρονιά;

Δίνεις τα στοιχεία του πάρκου σε ένα αρχείο και παίρνεις μια μελέτη στα ελληνικά (`report.html`) και όλα τα νούμερα σε `results.json`.

> Αυτό το repository είναι ένα shadow run του Pseudo Project του ODYCEO (ΕΜΠ): μια πλήρης δοκιμαστική εκτέλεση, για να φανούν από πριν τα εμπόδια και οι αποφάσεις που θα συναντήσουν οι ομάδες. Δεν είναι επενδυτική ή νομική συμβουλή.

## Τι κάνει

- **Κανόνες.** Υλοποιεί το άρθρο 11Γ του ν. 4685/2020: σταθμός 11Α (φορτίζει μόνο από το ΦΒ, κρατά την ενίσχυση, όριο έγχυσης 07:00 έως 19:00) και 11Β (φορτίζει και από το δίκτυο, χάνει την ενίσχυση). Ελάχιστη χωρητικότητα μίας ώρας, αμοιβή της ενέργειας της μπαταρίας σε τιμή αγοράς, κανόνας αρνητικών τιμών. Κάθε κανόνας έχει πηγή και ημερομηνία επαλήθευσης.
- **Αγορά.** Σενάρια 15 ετών, όχι πρόβλεψη. Οι τιμές βγαίνουν από το υπολειπόμενο φορτίο της χώρας, και οι μπαταρίες της χώρας μπαίνουν όσο η διαφορά τιμών καλύπτει το κόστος τους. Έτσι η συμπίεση της διαφοράς μεσημέρι προς βράδυ υπολογίζεται, δεν υποτίθεται.
- **Καιρός.** Κάθε έτος προσομοιώνεται με εννέα πραγματικά καιρικά έτη, ώστε ηλιοφάνεια, τιμές και περικοπές να κινούνται μαζί.
- **Λειτουργία.** Βελτιστοποίηση ανά 15λεπτο με κοινό όριο έγχυσης, περικοπές και φθορά.
- **Μέγεθος.** Η ισχύς και η χωρητικότητα είναι αποτέλεσμα. Το «καμία μπαταρία» είναι πάντα υποψήφια απάντηση.
- **Ρίσκο και τράπεζα.** NPV, IRR, απόσβεση, P50 και P90, DSCR στον κακό χρόνο, ποιος παράγοντας οδηγεί το ρίσκο, ποιο κόστος ή επιδότηση φέρνει την επένδυση στο μηδέν.
- **Ρυθμιστικός έλεγχος** για το συγκεκριμένο πάρκο και αποτέλεσμα με εναλλακτικές αναγνώσεις των ασαφών κανόνων.

## Γρήγορη εκκίνηση

```bash
git clone https://github.com/Yiannosste/BESS-DSS && cd BESS-DSS
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
```

```bash
bessdss study examples/parks/park_a_fip_1mw.yaml --out results/park_a
```

Το πρώτο τρέξιμο κατεβάζει την παραγωγή του πάρκου από το PVGIS και χτίζει την κρυφή μνήμη της αγοράς (περίπου 5 λεπτά σε 4 πυρήνες). Τα επόμενα θέλουν 6 έως 8 λεπτά ανά πάρκο. Άνοιξε το `results/park_a/report.html`. Έτοιμες μελέτες για τα παραδείγματα υπάρχουν στο [`docs/example_studies/`](docs/example_studies/).

Άλλες εντολές:

```bash
bessdss compliance examples/parks/park_b_fit_500kw.yaml --category 11A --power 0.25 --energy 0.6
```

```bash
bessdss market
```

```bash
pytest -q
```

## Το αρχείο του πάρκου

```yaml
park:
  name: "Το πάρκο μου"
  lat: 39.64
  lon: 22.42
  pv_dc_kwp: 1100              # ισχύς πλαισίων
  pv_ac_kw: 1000               # ισχύς μετατροπέων
  grid_export_limit_kw: 1000   # μέγιστη ισχύς έγχυσης από τους όρους σύνδεσης
  commissioning_date: "2021-03-15"
  static_injection_cap_frac: 1.0   # 0.73 αν το πάρκο έχει το όριο του 2022
  support: {kind: fip, price_eur_mwh: 65.0, end_year: 2041}   # fit | fip | merchant | ppa
  curtailment_multiplier: 1.0      # περικοπές της περιοχής σε σχέση με τον μέσο όρο της χώρας
  measured_production_csv: null    # προαιρετικά: CSV με στήλες ts_utc, power_kw
regulatory: {}        # προαιρετικά: άλλη ανάγνωση κανόνων, π.χ. {cap_11a_frac_of_installed: 0.40}
battery: {}           # προαιρετικά: απόδοση, παράθυρο φόρτισης, όριο κύκλων
finance_overrides: {} # προαιρετικά: π.χ. {capex_subsidy_frac: 0.3, gearing: 0.6}
```

Όλα τα πεδία με τις προεπιλογές τους είναι στο `src/bessdss/config.py`. Τρία έτοιμα παραδείγματα στο `examples/parks/`.

## Πού είναι τι

| `src/bessdss/` | Ο κώδικας: `dispatch` (λειτουργία), `market` (σενάρια αγοράς), `battery` (φθορά), `finance`, `sizing`, `risk`, `regulatory`, `report`, `data`, `pv` |

| `data/processed/` | Πραγματικά δεδομένα αγοράς και η βαθμονόμηση του μοντέλου |
| `examples/parks/` | Τρία παραδείγματα πάρκων |
| `scripts/` | Λήψη δεδομένων, πειράματα, σύγκριση με PySAM, παραγωγή εγγράφων |
| `tests/` | 79 tests, δεμένα με τα requirements REQ-01 έως REQ-18 |

## Αναπαραγωγή από την αρχή

```bash
pip install -e ".[data,experiments,benchmark]"   # επιπλέον πακέτα για λήψη δεδομένων, πειράματα και PySAM
python scripts/fetch_market_data.py        # δεδομένα αγοράς (35 έως 45 λεπτά την πρώτη φορά)
python scripts/fetch_nasa_power.py         # ακτινοβολία 2015 έως σήμερα
python scripts/fetch_pvgis_points.py       # παραγωγή ΦΒ σε 8 περιοχές
bessdss calibrate                          # βαθμονόμηση του μοντέλου αγοράς
bessdss study examples/parks/park_a_fip_1mw.yaml
python scripts/run_experiments.py          # τα πειράματα του ημερολογίου καινοτομίας
python scripts/benchmark_pysam.py          # σύγκριση με το NREL SAM (θέλει pip install NREL-PySAM)
python scripts/merge_regulatory.py && python scripts/build_docs.py   # έγγραφα από τα μητρώα
```

Οι σπόροι τυχαιότητας είναι σταθεροί, άρα το ίδιο αρχείο δίνει το ίδιο αποτέλεσμα.

## Τι να ξέρεις πριν το εμπιστευτείς

- **Δεν προβλέπει τιμές.** Το μοντέλο τιμών έχει σφάλμα περίπου ±25% στη διαφορά τιμών όταν δοκιμάζεται σε χρονιά που δεν έχει δει. Το σφάλμα αυτό είναι μέσα στην ανάλυση κινδύνου.
- **Οι κανόνες αλλάζουν.** Το άρθρο 11Γ άλλαξε δύο φορές μέσα στο 2026. Όλοι οι κανόνες επαληθεύτηκαν στις 10 Νοεμβρίου 2026. Τέσσερις κρίσιμοι είναι ασαφείς και το εργαλείο δείχνει το αποτέλεσμα με κάθε ανάγνωση.
- **Τα κόστη και οι όροι δανείων είναι εκτιμήσεις.** Δεν βρέθηκε δημόσια ελληνική προσφορά EPC ούτε όροι ελληνικής τράπεζας.
- **Δεν μετρά** έσοδα από εξισορρόπηση και ενδοημερήσια αγορά, ούτε το όφελος από μικρότερες αποκλίσεις.
- **Άδεια δεδομένων.** Οι τιμές της αγοράς επόμενης ημέρας δεν επιτρέπεται να αναδημοσιεύονται χωρίς άδεια του HEnEx. Αν το repository γίνει δημόσιο, τα αρχεία τιμών πρέπει να φύγουν και να μείνουν μόνο τα scripts λήψης. Λεπτομέρειες στη δυσκολία DIF-019.
