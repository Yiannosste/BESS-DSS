# Stage 3: Πρώτη εκδοχή end-to-end

Στόχος του stage: repository με σωστές πρακτικές και μια πρώτη απλή εκδοχή που δουλεύει από την αρχή ως το τέλος.

## 1. Τι στήθηκε

- **Repository:** `Yiannosste/BESS-DSS` στο GitHub, κλάδος εργασίας `claude/tender-sagan-tnf093`. Οι ομάδες θα δουλέψουν στο GitLab. Εδώ ζητήθηκε GitHub (D-009).
- **Δομή:** πακέτο Python `bessdss` κάτω από `src/`, εγκατάσταση με `pip install -e .`, εντολή `bessdss`.
- **Μητρώα σε YAML ως πηγή αλήθειας** και έγγραφα που παράγονται από αυτά (D-002). Το CI αποτυγχάνει αν τα έγγραφα δεν συμφωνούν με τα μητρώα.
- **CI:** GitHub Actions σε κάθε push (`.github/workflows/ci.yml`): `ruff`, 78 tests σε Python 3.11 και 3.13, έλεγχος συγχρονισμού μητρώων και εγγράφων. Τα tests τρέχουν χωρίς δίκτυο, πάνω στα δεδομένα του repository.
- **Commits:** μικρά και συχνά, με μήνυμα που λέει τι άλλαξε. Το ιστορικό δείχνει τη σειρά: σκελετός και LP, κανόνες αμοιβής, δεδομένα και μοντέλο τιμών, νομικές κατηγορίες, αλυσίδα μελέτης, ρίσκο και αναφορά.

| Βήμα | Τι έτρεξε πρώτη φορά | Τι ήταν ακόμη απλοποιημένο |
