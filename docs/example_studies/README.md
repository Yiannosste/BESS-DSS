# Έτοιμες μελέτες για τα παραδείγματα

Κάθε φάκελος έχει την αναφορά (`report.html`, ανοίγει σε browser) και όλα τα νούμερα (`results.json`), όπως βγήκαν από το `bessdss study` στις 11 Νοεμβρίου 2026.

| Φάκελος | Πάρκο | Απάντηση |
|:-|:-|:-|
| `park_a/` | 1 MW με ΣΕΔΠ, Λάρισα (`examples/parks/park_a_fip_1mw.yaml`) | Όχι |
| `park_b/` | 0,5 MW παλιό FiT, Τρίπολη (`examples/parks/park_b_fit_500kw.yaml`) | Όχι, και δεν πληρείται η επιλεξιμότητα |
| `park_c/` | 5 MW χωρίς ενίσχυση, Κοζάνη (`examples/parks/park_c_merchant_5mw.yaml`) | Όχι |
| `park_c_subsidy/` | Το ίδιο με επιδότηση κεφαλαίου 60% (υπόθεση εργασίας) | Μόνο με ρίσκο |

Τα πάρκα είναι ενδεικτικά, όχι πραγματικά. Οι μελέτες δεν είναι επενδυτική ή νομική συμβουλή.
